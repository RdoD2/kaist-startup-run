LEARNINGS
=========
- Phaser 3 scene 초기화: `scene: [Class]` 자동 시작 시 init에 empty data 전달 → 후속 start가 재초기화 안 함. `game.scene.add(key, class, autoStart=true, data)` 패턴이 안전.
- Next.js dynamic import + ssr:false가 Phaser SSR 호환성 해결 (window 참조 안전)
- TailwindCSS arbitrary value `text-[Npx]`에 대한 sed 일괄 변환 — 역순(큰→작은) 순서로 처리해야 chain replacement 회피
- mockPlayer를 localStorage 단일 키에 저장 → 페이지 navigate 간 상태 보존. usePlayer cache와는 별도 키 (mock_player는 api 내부 상태, player_cache는 UI 컴포넌트용)
