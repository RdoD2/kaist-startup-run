LEARNINGS
=========
- @vercel/og는 TTF/OTF/WOFF 지원, WOFF2 미지원. 매직 바이트(0x00010000=TTF, 'OTTO'=OTF) 검증으로 fallback 안전성 확보.
- WebAudio는 첫 user-gesture 이후 AudioContext 생성 필수 (autoplay policy).
- Phaser Container로 hitbox/sprite 분리 → 충돌은 AABB rect, 시각은 컨테이너. 깔끔.
- Next.js Edge route에서 fetch GitHub raw는 SSR/edge 환경에서 가능 (테스트됨).
- WebAudio 모든 API SSR 가드 필수 (window undefined).
